# D5 SLOY — статус для независимого ревью · 12.11.2026

**Что передаётся:** полный редизайн демо-сайта мраморного ателье в Дубае (вымышленный бренд SLOY) по ТЗ владельца: показ продукции, сценарии B2C/B2B, путь к заявке, международная подача. Работа локальная: коммита, публикации и деплоя не было. База — HEAD `e901405`, всё новое лежит в рабочем дереве незакоммиченным.

**Что сделано**
- Новая визуальная система: тёплая нейтральная гамма; шрифты Cormorant Garamond, IBM Plex Sans и IBM Plex Sans Arabic (самохостинг, OFL); шкала из 9 размеров на токенах.
- Структура страницы: развилка «для дома / для профессионалов», коллекция из 6 предметов с просмотрщиком, библиотека из 6 камней и 4 обработок с запросом образцов, блок для профессионалов, FAQ, шоурум (вместо павильона), форма с тремя типами запроса (проект / образцы / консультация) и локальный TXT.
- Языки: EN (по умолчанию), RU, AR (RTL, зеркальная вёрстка).
- Фото: 7 кадров Runway (Nano Banana 2.1), которые сгенерировал владелец; на сайте подписаны как ИИ-визуализации. Образцы камня вырезаны из этих же кадров.

**Как проверить**
1. Из папки D5: `python3 -m http.server 4335 --bind 127.0.0.1`, открыть `http://127.0.0.1:4335/dist/`.
2. `node tests/redesign.mjs` — использует Chrome и playwright-core из D2. Каталог `OUT` должен быть новым: скрипт не перезаписывает существующий.
3. `shasum -a 256 -c SHA256SUMS` — проверка целостности всех файлов, кроме `docs/review-coordinator/`.

**Результат автора:** 186 PASS, 0 FAIL на `dist/`. Проверяются: 4 ширины × 3 языка, вёрстка и контраст, цели нажатия, сценарии формы, просмотрщик, меню, RTL, работа без JS, отказ изображения. Свидетельства — `screenshots/photos-2026-11-12/`.

**Не проверено:** Safari и Firefox, реальные устройства, экранные дикторы, масштаб 200%, полный WCAG. Арабский перевод не вычитан носителем.
