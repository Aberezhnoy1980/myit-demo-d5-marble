`node --check app.js` — успешно. Сумма всех исходников и всех четырёх JPEG 626 454 байта; это верхняя оценка передачи без HTTP-заголовков, не замер сетевого waterfall. JS gzip: 1092 байта (`gzip -c app.js | wc -c`); целевые 1 МБ и 60 КБ gzip не превышены по этой оценке. Остальные фактуры загружаются при выборе.

Не проверено: настоящий масштаб браузера 200%, полная клавиатурная последовательность и возврат фокуса после закрытия, фактический режим reduced motion, работа при отключённом JS, длинный ввод на всех ширинах, 404/network waterfall, размещение под префиксом и сторонние браузеры. В CSS предусмотрен reduced motion, у изображений есть alt; в noscript скрыты неработающие элементы и приведено объяснение. Это не доказательство WCAG 2.2 AA.


## Ограниченная ревизия после замечаний координатора

- При ширинах 390 и 1440 CSS px выбранные заголовки имеют цвет `rgb(69,82,59)`: на фоне аудитории `rgb(238,236,229)` контраст 7,04:1; на фоне фактуры `rgb(222,222,212)` — 6,15:1. Расчёт по относительной яркости WCAG на вычисленных цветах.
- У выбранных элементов видна надпись «Выбрано ✓», программное состояние `aria-pressed` сохранено. Переключение аудитории и фактуры и оба пути до локального резюме повторены.
- Отказ `dark.jpg` проверен временным переименованием файла с последующим восстановлением: показано сообщение, изображение скрыто, кнопка увеличения заблокирована, диалог закрыт. Выбор доступной фактуры восстановил изображение и кнопку; Escape закрыл просмотр и вернул фокус на кнопку. Ожидаемая ошибка отсутствующего файла при этой проверке не является ошибкой в восстановленном комплекте.
- Демо-маркер виден на первом экране телефона. Полностраничные `screenshots/390.png` и `1440.png` получены установленным Chrome через существующий Playwright Core из окружения D2 исключительно для проверки, без установки и зависимости продукта. Проверено `innerWidth` и `scrollWidth`: 390/390 и 1440/1440. JPEG — копии этих снимков.
- Не проверены настоящий browser zoom 200%, VoiceOver, физические устройства, другие движки и полный аудит доступности. Это авторская проверка, не независимая приёмка.

Объём файлов `dist/`: 630 803 байта без HTTP-заголовков; gzip JS 1 869 байт (`gzip -c dist/app.js | wc -c`). Это оценка по файлам, не сетевой waterfall. Снимки сняты с `deviceScaleFactor: 1` при заданном viewport; контраст относится к выбранным пунктам, не всему сайту.

Не проверены настоящий browser zoom 200%, VoiceOver, физические устройства, Safari и Firefox, полный аудит WCAG 2.2 AA, реальный хостинг/HTTPS и права третьих лиц на интерьер для конкретного публичного контекста. Тест отказа clipboard — имитация отказа API, а не проверка каждого браузерного разрешения. Скачать означает инициировать сохранение: браузер определяет итоговое место и решение пользователя.

При первом прогоне сервер зафиксировал 404 автоматического запроса `/favicon.ico`. Добавлен пустой встроенный значок; итоговый повтор 19/19, в просмотренном журнале сервера все запросы вернули 200.
