# СЛОЙ — локальный демонстрационный кейс D5

Вымышленный бренд: два сценария подготовки запроса о поверхности, выбор иллюстративной фактуры, параметры, копирование и скачивание UTF-8 TXT. Запрос никуда не отправляется; контактов, цены, backend и интеграций нет. Это передача на независимое ревью, не разрешение публикации.

## Запуск и комплект

Никакой установки и сборки зависимостей. Из папки D5:

```sh
mkdir -p dist/assets
cp index.html style.css app.js dist/
cp assets/*.jpg dist/assets/
python3 -m http.server 4335 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4335/dist/ . Остановить свой сервер Ctrl+C; при занятом порте выбрать свободный. `dist/` — публичный комплект: HTML, CSS, JS и четыре JPEG; без docs, тестов и снимков. Перед повторной упаковкой убедиться, что в `dist/` нет посторонних файлов. Проверенное окружение: Python 3.11.8, Node.js 22.23.4, Chrome 157.0.8103.38. Node нужен только для авторской проверки, продукт от него не зависит.

Все пути относительные. Проверка под локальным префиксом `/dist/` выполнена; конкретный будущий хостинг, HTTPS и его правила маршрутизации не проверены. Копирование требует доступного Clipboard API (обычно HTTPS или localhost); при отказе текст можно выделить вручную. Браузер управляет сохранением TXT. Для возможного размещения передать содержимое `dist/` в согласованную папку; откат — восстановление предыдущей версии на выбранной площадке. Размещение и откат не выполнялись и требуют отдельного решения.

Документы — `docs/`; тестовая команда `node tests/verify.mjs` использует уже существующий локальный Playwright Core из D2 только для проверки, не входит в продукт и не устанавливается автоматически. Проверка требует работающий сервер на 4335 и установленный Chrome, пути заданы в скрипте. Пример фактически скачанного запроса — `examples/zapros-po-proektu.txt`. Снимки — `screenshots/completion-390.png`, `completion-1440.png`, `request-390.png`.

`SHA256SUMS` охватывает все файлы D5, включая `dist/`, документацию, примеры, тест и снимки, кроме себя и чужого `docs/review-coordinator/`. Проверка: `shasum -a 256 -c SHA256SUMS`.
